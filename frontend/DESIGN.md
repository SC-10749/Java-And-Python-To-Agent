# Fieldnote 增长运营台

## 视觉主题与氛围
广告投放与用户增长运营台应像一份可行动的增长周报：安静、清楚、可信。页面以留白和分隔线组织增长数据，不把每一块信息都塞进卡片。

## 设计参数
- 视觉冒险度：7 / 10。用编辑式标题、非等宽内容分区与克制强调色建立记忆点。
- 动效强度：6 / 10。页面进入、抽屉和数据反馈清晰可感，但高频操作保持即时。
- 信息密度：7 / 10。首屏同时呈现增长指标、注册与首单趋势、增长路径和风控待办。

## 色板与角色
- 纸张底色：`#F5F4EF`
- 内容底色：`#FBFAF7`
- 墨色文字：`#22303B`
- 信息蓝：`#245A79`
- 成功绿：`#247153`
- 警示橙：`#A55B21`
- 风险红：`#AF4440`

## 排版规则
中文 UI 使用 `PingFang SC / Microsoft YaHei / Noto Sans SC` 系统栈；金额、比例和日期使用等宽数字。标题紧凑、正文克制，禁止使用斜体和渐变文字。

## 组件样式
表格与指标优先使用顶部分隔线、行分隔线和留白。按钮为小圆角实体或描边；焦点状态使用柔和蓝色外框。数据状态用颜色加文字，不只依赖颜色。

## 布局原则
桌面使用窄侧栏 + 内容画布；管理端只承载广告投放、注册转化、新人券、签到积分、邀请裂变、拼团秒杀、限时券、会员召回和风控。总览由指标带、注册与首单趋势、增长路径、活动执行和风险栏构成；用户端只提供领取、签到、邀请、限时活动、会员与优惠券入口。小屏折叠侧栏，内容单列排列。

## 深度层级
页面默认平面；只有下拉、通知和抽屉使用轻量阴影。禁止玻璃拟态、霓虹、外发光与大面积圆角卡片。

## Do's / Don'ts
- 使用真实感数据、明确状态和可操作的反作弊预警。
- 不使用过饱和渐变、空泛宣传文案或“卡片墙”。
- 表格内保持行高和对齐，金额与比例右对齐。

## 响应式
768px 以下隐藏桌面侧栏，工具栏换行；指标与分析面板折叠为单列，数据表允许横向滚动。

## Motion 哲学
只使用 `transform` 与 `opacity`。页面模块以短暂错峰进入，按钮反馈 120ms，弹层与提示 180–220ms；高频筛选不做入场动画，并为 `prefers-reduced-motion` 提供静态回退。

## 增长工具页
管理端新增五个面向增长运营的工具页：
- 增长漏斗：查看广告到达、注册、领券、首单和复购的转化路径及流失建议。
- 用户分群：按行为与标签选择可运营人群，并创建定向活动。
- 自动化运营：启停注册引导、领券催化和沉默召回流程。
- 营销规则：模拟规则命中并启停新人券、签到、邀请与秒杀规则。
- 奖励与审核：查询券、积分和成长值流水，审核高风险奖励。


## 认证入口
登录与注册采用独立路径：`/login`、`/register`。认证页以深蓝侧栏承载增长链路，表单区保持纸张底色和克制的边框交互；手机号、密码、确认密码和协议勾选均提供前端校验。当前为前端演示态，成功提交后进入管理端总览，后续可替换为 Spring Boot 认证接口。


## RAG 智能客服
- 右下角提供常驻客服入口，管理端进入 RAG 客服运营页，用户端进入智能咨询页。
- 管理端包含回答链路、检索证据、高频问题和知识缺口；知识库管理页支持前端演示上传 PDF、Word、Markdown、TXT 文档。
- 用户端对话展示回答来源，前端根据问题关键词模拟检索结果。生产接入时可由 Spring Boot 负责权限、会话和文档任务，MinIO 存储原文档，Milvus 保存向量，Ollama 提供本地模型推理。
